 HR Analytics: Employee Attrition & Workforce Insights

Project Overview

This project analyses employee data to explore workforce characteristics and employee attrition patterns. It combines Python-based data preparation and exploratory data analysis, SQL queries for filtering and aggregation, and an interactive Power BI dashboard to communicate workforce trends and support data-driven HR decisions.

Business Objectives

* Understand employee attrition patterns across departments and employee characteristics.
* Explore workforce data to identify trends and potential retention concerns.
* Use SQL to filter, group, and summarise employee data for analysis.
* Present key workforce metrics through an interactive Power BI dashboard.
* Support HR decision-making with clear, data-based insights.

Tools & Technologies

* Python: Data preparation and exploratory analysis
* Pandas & NumPy: Data manipulation and cleaning
* Matplotlib & Seaborn: Exploratory data visualisation
* SQL: Data filtering, grouping, and aggregation
* Power BI: Interactive dashboard development

Project Workflow

1. Data Preparation: Cleaned and transformed employee records using Pandas and NumPy to improve data quality.
2. Exploratory Data Analysis: Examined workforce characteristics and attrition patterns using Python visualisations.
3. SQL Analysis: Applied filtering and aggregation queries to investigate attrition across departments and employee attributes.
4. Dashboard Development: Designed interactive Power BI reports using KPI cards, charts, slicers, and filters to communicate workforce trends.

Repository Contents

* HR_Employee_Attrition.ipynb — Python notebook for data preparation and exploratory analysis.
* HR_Employee_Attrition.sql — SQL queries for employee attrition analysis.
* README.md — Project documentation.
